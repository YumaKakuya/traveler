# Contributing to Traveler.

Thank you for your interest in contributing to Traveler.

## Contribution Policy (B-3)

This policy applies from Phase 0 through v0.1.0 release.

| PR class | Policy |
|----------|--------|
| Typo / documentation correction | Open. Merge with light review. |
| Test addition (covering existing behaviour) | Open. Merge after CTO/CPO review. |
| Small bug fix (single-file, single-concern) | Open. Merge after CTO/CPO review. |
| Feature addition | **Discussion-first.** No PR until CEO has reviewed the Discussion thread. |
| Architecture change | **Discussion-first + CEO + Wizard escalation.** |
| Phase-0 timeframe (first two weeks) | External PRs **CLOSED** until v0.1.0 ships. Issues remain open. |

After Phase 0 closes, large PRs (feature / architecture) remain Discussion-first. Small PRs (typo, doc, test, small-fix) continue to be accepted.

## CLA Signing

All contributors must sign the Contributor License Agreement (CLA) before their first PR can be merged.

**Signing instruction:** Add the following comment to your PR:

```
I have read and signed the CLA
```

See [CLA.md](./CLA.md) for the full agreement text.

## Information Hygiene Rules

These rules apply to all public contributions: commit messages, PR bodies, and Issues.

**Do NOT:**
- Mention vendor names (Claude, Anthropic, OpenAI, Gemini, etc.) as authorship attribution in public artefacts
- Use `Co-Authored-By` lines
- Flag AI-generated content as such in public artefacts

These rules protect contributor privacy and maintain information hygiene across the project. They are inherited from the organisation-wide policy and apply identically to Traveler.

## Getting Started

1. Open an Issue to discuss proposed changes (especially for feature / architecture PRs)
2. For small fixes: open a PR directly with a clear description
3. Sign the CLA before your first merge
4. Ensure all commits use clear, vendor-name-free messages

## Questions

For questions or discussion, open a GitHub Discussion. For bugs or concrete issues, open a GitHub Issue.
